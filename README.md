# Haul assistant skills

Instructions that teach an AI assistant (Claude, ChatGPT, Grok, Muse…) how to use the **Haul** connector well.
Haul is a consumer post-purchase app: one place for every order from every store, built from the shopper's own
order emails, with carrier tracking and the place each store takes returns.

- `skills/haul/SKILL.md` — when to call which Haul tool, Haul's vocabulary, and the rules an assistant must keep
  (nothing is sent without the person's confirmation; email text only when the question needs it).
- Connector address and setup: https://www.myhaul.ai/assistants · Privacy: https://www.myhaul.ai/privacy

No secrets, no user data, nothing executable. MIT licensed.
